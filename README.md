# Astroverse

Локальный интерактивный 3D-планетарий: Солнечная система → окрестности Солнца → Млечный Путь.

## Возможности

- Три масштаба просмотра: «Солнечная система», «Окрестности Солнца» и «Млечный Путь» (балдж, перемычка, спиральные рукава, положение Солнца)
- Каталог из **3471 объекта**: планеты, карликовые планеты, луны, астероиды, кометы, звёзды, экзопланеты, туманности, скопления, галактики и чёрные дыры
- Процедурные текстуры тел, атмосферы, кольца, пояс астероидов и пояс Койпера
- Движок времени: пауза, шаги ±1 день, ускорение симуляции (×1 — один день симуляции в секунду)
- Карточки объектов с описанием, телеметрией (масса, радиус, температура, период и т. д.) и фактами; мифология и история — для тел Солнечной системы
- Поиск по имени, латинскому названию и описанию
- Интеграция с NASA JPL Horizons: эндпоинт `/api/live-ephemeris` возвращает реальные позиции планет (кэш на 1 час)

## Запуск одной командой (Docker)

Нужен Docker Desktop / Docker Compose.

```bash
docker compose up --build
```

Открыть: http://localhost:5173 (nginx раздаёт собранный frontend и проксирует `/api` на backend).

Остановка: `Ctrl+C`, затем при необходимости `docker compose down`.

## Локальный запуск (без Docker)

Нужны Python 3.10+ и Node.js 18+.

### Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

### Frontend (в другом терминале)

```bash
cd frontend
npm install
npm run dev
```

Открыть: http://localhost:5173 — Vite проксирует `/api` на `http://127.0.0.1:8000`.

### API

| Эндпоинт             | Описание                                            |
|----------------------|-----------------------------------------------------|
| `GET /api/health`    | Статус и количество объектов                       |
| `GET /api/objects`   | Каталог; параметры `q` (поиск) и `kind` (тип тела)  |
| `GET /api/live-ephemeris` | Реальные позиции планет от NASA JPL Horizons  |

## Данные каталога

Каталог лежит в `data/objects.json`. Пересобрать его после правок `data/build_catalog.py`:

```bash
python3 data/build_catalog.py
```

## Архитектура

```text
Astroverse
├── frontend  React + Three.js + Vite (src/bodies — меши и текстуры,
│             src/hooks — three/время/данные, src/components — UI)
├── backend   FastAPI (отдаёт каталог, проксирует JPL Horizons)
└── data      JSON-каталог объектов + скрипт сборки
```

Масштабы визуализации сжаты (иначе Юпитер и галактика не умещаются в одном кадре). Числа в карточках — справочные, по NASA / Gaia / IAU.
