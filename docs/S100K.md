# Synthetic S-100k

Opt-in `tests.s100k_provider`: SQLite100секторов×1000, API/UI явно synthetic;
обычная сцена — пять DE440s centers. Production physical
manager/layer/renderer/flight, без полного JSON. Команды `make scene SCENE=s100k`,
`make scene-down` и проверки — [tests/README](../tests/README.md).

## Данные и обычный physical-путь

Решётка400×250: `X=(column−199.5)×4000km`, `Z=(row−124.5)×4000km`, Y=0,
ICRF/SSB; ID50001 совпадает с50000 без раздвижения. Векторы стационарны при
supported requested UTC; evaluated_at/JD TDB — момент запроса, accuracy=null.
Камера[0, 8, 24] смотрит на origin; при1920×1080 все100000centers во frustum.
Перекрытия5/15px маркеров: submitted не означает100000различимых дисков.

epsilon1e−6ms — только IEEE noise. Пауз>50ms не допускается; draw calls≤1.
Admission≤200000resident+staging+in-flight/64MiBserialized/512MiBdecoded estimate,
response≤1MiB/1000rows; 4workers/queue≤128. Обычный профиль прежний.
Глобальные IDs/identities, UTC/JD/revisions проверяются до публикации.

Flat decode/merge/staging отменяемы; renderer порции256rows, atomic sync commit.
Continuous coalescing ждёт renderer acknowledgement; explicit context отменяет
старую работу. Rebase/picking читают целый frame; остальные инварианты —
[PHYSICAL_LOD](PHYSICAL_LOD.md).≤32L1/128checks за RAF: полный обход≤782RAF.
Picking AABB256slots, затем screen-distance/depth/lexical ID; log-depth сохранён.
Capacity131072×28B=3670016B GPU и столько же staging, nominal cap7340032B.
Decoded estimate не RSS; driver memory неизвестна. CPU/GPU tolerances —
[NAVIGATION](NAVIGATION.md); массовая hierarchy/L2/поверхности открыты.
